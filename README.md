# Mastermind-Game
The Mastermind game that was implemented text base on python
Number Guessing Game
A simple Python terminal game where players try to guess a randomly generated number before running out of attempts.

Description
This project was created to practice Python fundamentals such as functions, loops, input validation, random number generation, and game logic.

The player selects a difficulty level, which determines the number of digits in the secret number. After each guess, the game provides feedback on how many digits are correct and how many are in the correct position.
The goal is to correctly guess the entire number within 12 attempts.

Features
  Random number generation
  Adjustable difficulty level
  Input validation
  Guess feedback system
  Limited number of attempts
  Win and lose conditions
How to Play
  1. Run the program.
  2. Enter your username.
  3. Choose a difficulty level.
  The difficulty level determines the length of the secret number.
  4.Enter guesses until you find the correct number or run out of attempts.
  5.Use the feedback provided after each guess to narrow down the solution.
